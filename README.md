## 📚 Design Philosophy

While implementing each problem, the focus is on:

* Identifying the right abstractions
* Assigning clear responsibilities
* Keeping the design simple
* Avoiding over-engineering
* Writing code that is easy to extend and maintain

Whenever possible, designs are kept flexible enough to support future requirements without unnecessary complexity.

---

## 📈 Learning Process

Each problem follows the same approach:

1. Gather requirements.
2. Identify core entities.
3. Define responsibilities.
4. Design interactions between objects.
5. Implement the solution.
6. Refactor and discuss improvements.
7. Consider possible extensions and trade-offs.
